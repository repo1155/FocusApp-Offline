# FocusApp

FocusApp is a React Native Android focus timer designed to help users stay on task with:

- Focus and break sessions
- Hard-focus / strict mode protection
- Emergency PIN unlock flow
- Session history and statistics
- App usage insights
- Local-only storage with no cloud sync

## Highlights

- Timer-driven focus workflow for work and study sessions
- Adjustable focus and break durations with app-level limits
- History tracking with completion state, focus time, and break time
- Real app usage stats when Android usage access permission is granted
- Robust permission handling so the app stays stable when access is not allowed
- GitHub Actions workflow for automated Android APK and AAB builds

## Tech stack

- React Native 0.87.1
- TypeScript
- AsyncStorage for local persistence
- Android native modules for foreground detection and usage tracking
- Gradle / Android SDK for APK and AAB builds

## Local setup

### Prerequisites

1. Install Node.js 22+
2. Install JDK 17
3. Install Android Studio
4. Install the Android SDK packages:
   - Android SDK Platform 37
   - Build Tools 37.0.0
   - NDK 28.2.13676358
5. Set `ANDROID_HOME` and ensure `%ANDROID_HOME%\platform-tools` is on PATH

### Install dependencies

```powershell
npm install
```

### Run the app

Start Metro:

```powershell
npm start
```

Then in a second terminal:

```powershell
npm run android
```

## Android permission notes

The app asks for Android permission when needed for features such as:

- `PACKAGE_USAGE_STATS` for app usage insights
- `VIBRATE` for timer completion feedback

The app is written to remain stable even if the user denies permissions and will prompt again when the feature is used.

## Storage model

Session and settings data are persisted locally under the AsyncStorage key prefix:

```text
@focusapp/mvp/v1
```

The app stores focus sessions, break sessions, and user settings in a lightweight local format and merges defaults safely on startup.

## Build outputs

### Local Android builds

Debug APK:

```text

```

Release AAB:

```text
android/app/build/outputs/bundle/release/
```

### GitHub Actions

A CI workflow is included at:

```text
.github/workflows/android-build.yml
```

This workflow builds:

- debug APK
- release AAB
- uploaded artifacts in the GitHub Actions run

## Known build note

The app is configured to use JavaScriptCore instead of Hermes for compatibility in this environment. The project intentionally disables Hermes to avoid the missing `libhermestooling.so` startup crash seen in Android builds.

## Screens and features

- Home screen: focus timer, break status, emergency flow, completion popup
- History screen: completed sessions and session metadata
- Insights screen: trends and app-usage graphs when permission is available
- Settings screen: focus/break durations, hard focus mode, pin setup, and history reset
